# Industrial Maintenance Management

## Descrição do Projeto

O **Industrial Maintenance Management** é um projeto de banco de dados desenvolvido para auxiliar no gerenciamento de ordens de serviço relacionadas à manutenção industrial.

A solução terá como finalidade organizar informações sobre equipamentos, técnicos, setores, tipos de manutenção e ordens de serviço, permitindo o registro e acompanhamento das atividades de manutenção realizadas no ambiente industrial.

## Objetivo da Solução

O objetivo do projeto é desenvolver uma solução de banco de dados utilizando **MongoDB** para armazenar e gerenciar informações relacionadas aos processos de manutenção industrial.

A solução deverá possibilitar o controle das ordens de serviço, permitindo registrar informações como:

* Equipamento que necessita de manutenção;
* Tipo de manutenção realizada;
* Técnico responsável;
* Data de abertura e conclusão;
* Prioridade da ordem de serviço;
* Status da manutenção;
* Descrição do problema;
* Serviços realizados;
* Peças e materiais utilizados.

Com isso, o sistema poderá facilitar a organização das atividades de manutenção e o acompanhamento do histórico dos equipamentos.
